# Contributing

Thank you for helping improve AION 2 Companion Overlay.

## Development

Requirements: Node.js 20+, pnpm, Rust stable, WebView2 and Visual Studio Build Tools with the Desktop development with C++ workload.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri build
```

Keep recommendations deterministic and source-labelled. Do not add scraping, game-process access, packet capture, automation, copyrighted article text or unlicensed databases. Regional or community facts must retain region, patch, source and confidence metadata.

Submit focused pull requests and describe the verification performed. Security vulnerabilities should follow `SECURITY.md`, not a public issue.
